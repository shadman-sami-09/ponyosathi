# পণ্যসাথী (Ponyosathi)

Bangladesh's leading wholesale product discovery and buying platform.

**Tagline:** "Find. Compare. Buy Wholesale. Resell."

## Overview

Ponyosathi is a web platform that aggregates wholesale products from major Bangladeshi companies and brands, making it easy for retailers, resellers, and small businesses to:

- Discover products from leading companies
- Compare wholesale prices
- Research profit margins
- Make informed purchasing decisions

## Features

- **API:** Axios
- **Backend:** Node.js/Express (planned)

## Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/shadman-sami-09/ponyosathi.git
cd ponyosathi

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Important Principles

1. **Price Transparency:** All prices are clearly marked as verified, listed, or estimated
2. **Source Attribution:** Every product includes information about where price data came from
3. **Date Tracking:** Price source dates are recorded
4. **No False Claims:** We never claim unverified prices as official wholesale prices
